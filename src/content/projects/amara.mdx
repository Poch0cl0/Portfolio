# Amará

Plataforma web de bienestar emocional con seguimiento, asistente conversacional e integración social.

## Contexto

Proyecto personal desplegado en Vercel con demo pública.

## Solución

Next.js 16 App Router, Supabase con RLS, API Routes autenticadas y asistente IA con contexto dinámico.

## Resultados

- Demo pública en Vercel
- Seguimiento emocional con calendario y estadísticas
- i18n ES/EN
