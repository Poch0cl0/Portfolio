# ObstetriCare

Sistema de Alerta Temprana para prevención de parto prematuro.

## Contexto

Proyecto académico/profesional orientado al sector salud materno-infantil, con enfoque en alerta temprana y gestión clínica.

## Solución

Arquitectura full-stack con FastAPI, React/TypeScript, PostgreSQL, Redis y pipeline ML con consenso ponderado sobre variables clínicas.

## Resultados

- Sistema funcional
- Documentación técnica
- Pruebas automatizadas con pytest
