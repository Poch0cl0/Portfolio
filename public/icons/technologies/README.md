# Technology logos

Local SVG brand silhouettes from [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under CC0 (see LICENSE.md). Icons were retrieved from the version 16 npm package; OpenAI comes from version 14 because it is absent in version 16. Brand colors are applied to the local files. Logos remain the property of their respective owners.

Generic concepts, algorithms, and tools without an included brand asset use Lucide semantic icons; these are not presented as official logos. No runtime requests to an external icon CDN are required.
